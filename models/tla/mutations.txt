# Deliberate defects, one per checked invariant.
#
# A specification TLC has never reported a violation on is not evidence. Each
# block below breaks one thing in one module and names the invariant that must
# notice; `go run ./tools/tlatools mutate` (make tla-mutate) applies each to a
# copy of this directory, reduces the configuration to that one name -- so the
# violation is attributable rather than "whichever invariant the list tripped
# first" -- and fails when TLC finds no counterexample.
#
# Format: one block per mutation, headed "## Config/Invariant[/label]", then
#   module: <module the text belongs to>   (default: the config's own module)
#   why:    <the defect, in one line>
#   old: / new:  literal text blocks, each line prefixed with "  | "
# The old text must occur exactly once in the module, which is what keeps a
# mutation from silently applying somewhere else after the spec is edited.
#
# tools/modelcheck fails when a configured invariant has no mutation here, so
# an invariant cannot be added to a .cfg without one.

## Settlement/TypeOK
why: a committed settlement leaves the owner behind, so a delivery that is not settling has one
old:
  |   /\ state' = "settled"
  |   /\ pending' = "active"
  |   /\ owner' = None
new:
  |   /\ state' = "settled"
  |   /\ pending' = "active"
  |   /\ UNCHANGED owner

## Settlement/OneWinner
why: Begin drops the active check, so a second racer enters settling behind the first
old:
  |   /\ IF state = "active" /\ token[r] = gen
new:
  |   /\ IF token[r] = gen

## Settlement/NoDoubleTerminal
why: Retry accepts a settled delivery, so one generation is terminally settled twice
old:
  |   /\ IF state \in {"active", "unknown"} /\ token[r] = gen
new:
  |   /\ IF state \in {"active", "unknown", "settled"} /\ token[r] = gen

## Settlement/StaleRejected
why: Begin drops the generation check, so a stale or forged handle settles the delivery
old:
  |   /\ IF state = "active" /\ token[r] = gen
new:
  |   /\ IF state = "active"

## Settlement/LeaseLostNeverSettles
why: a revocation records the lost lease but leaves the delivery active, so its holder still settles it
old:
  |   \/ /\ state = "active"
  |      /\ state' = "idle"
  |      /\ lost' = lost \cup {gen}
new:
  |   \/ /\ state = "active"
  |      /\ UNCHANGED state
  |      /\ lost' = lost \cup {gen}

## Settlement/UnknownSticky

## FanoutReserve/TypeOK
why: a commit admits two records per reservation, so a subscription holds more than its capacity type allows
old:
  |      /\ held' = [s \in Subs |-> IF s \in take THEN held[s] + 1 ELSE held[s]]
new:
  |      /\ held' = [s \in Subs |-> IF s \in take THEN held[s] + 2 ELSE held[s]]

## FanoutReserve/NoOverflow
why: a reservation counts only what the subscription holds, not what other publishers have promised themselves
old:
  |      /\ IF held[s] + Reserved(s) < Cap
new:
  |      /\ IF held[s] < Cap

## FanoutReserve/ReservationBalance
why: a reservation is recorded without taking the subscription off the publisher's list, so one slot is accounted twice
old:
  |      /\ todo' = [todo EXCEPT ![p] = todo[p] \ {s}]
new:
  |      /\ UNCHANGED todo

## FanoutReserve/AtomicAllOrNothing
why: the atomic policy commits the reservations it holds even when it was refused somewhere
old:
  |   /\ LET take == IF Policy = "atomic" /\ refused[p] # {} THEN {} ELSE res[p] IN
new:
  |   /\ LET take == res[p] IN

## FanoutReserve/PartialAccounted
why: a publication reports only the subscriptions that refused it, so the ones it silently skipped are unaccounted
old:
  |      /\ lastRefused' = Subs \ take
new:
  |      /\ lastRefused' = refused[p]

## FanoutReserve/DropSlowAccounted
why: the drop-to-make-room branch fires whatever the policy, so a record is discarded under Atomic
old:
  |           ELSE IF Policy = "dropslow" /\ held[s] > 0
new:
  |           ELSE IF held[s] > 0

## FanoutReserveIndependent/Isolation
module: FanoutReserve
why: a reservation ignores the promises other publishers hold, so a full subscription bounds what another may take
old:
  |      /\ IF held[s] + Reserved(s) < Cap
new:
  |      /\ IF held[s] < Cap

## FanoutReserve/NoStarvation
why: a commit drops one subscription from what it admits, so a publication every subscription had room for is lost
old:
  |   /\ LET take == IF Policy = "atomic" /\ refused[p] # {} THEN {} ELSE res[p] IN
new:
  |   /\ LET take == IF Policy = "atomic" /\ refused[p] # {} THEN {} ELSE res[p] \ {FirstOf(Subs)} IN

## FanoutReserve/NoUnreservedAdmission
why: a commit admits to every subscription rather than to the ones it reserved, so a record lands past the capacity check
old:
  |   /\ LET take == IF Policy = "atomic" /\ refused[p] # {} THEN {} ELSE res[p] IN
new:
  |   /\ LET take == Subs IN

## Shutdown/TypeOK

  |   /\ dlqOpen' = dlqOpen \cup {r}
new:
  |   /\ UNCHANGED rstate
  |   /\ dlqOpen' = dlqOpen \cup {r}

## Shutdown/DLQBeforeAck
why: a failed dead-letter publication reports the record dead-lettered, settling it on a publication that never committed

  |             /\ released' = [released EXCEPT ![r] = released[r] + 1]
new:
  |        THEN /\ rstate' = [rstate EXCEPT ![r] = "deadlettered"]
  |             /\ released' = [released EXCEPT ![r] = released[r] + 1]

## Shutdown/NoLostInFlight

## MemoryLease/TypeOK
why: an admission dates the record two ticks past the clock bound, so its due time leaves the type
old:
  |   /\ \E d \in {0, 1} :
  |        /\ state' = [state EXCEPT ![r] = IF d = 0 THEN "ready" ELSE "delayed"]
  |        /\ due' = [due EXCEPT ![r] = now + d]
new:
  |   /\ \E d \in {0, 1} :
  |        /\ state' = [state EXCEPT ![r] = IF d = 0 THEN "ready" ELSE "delayed"]
  |        /\ due' = [due EXCEPT ![r] = now + d + 2]
