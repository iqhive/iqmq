# iqmq

One small, capability-honest, bytes-first Go API for publishing and consuming messages across Kafka, NATS/JetStream, NSQ, Google Cloud Pub/Sub, Amazon SQS, RabbitMQ, ActiveMQ, Redis Streams and Pulsar, plus a deterministic in-process memory engine.

!!! warning "Under construction"
    The project is being built increment by increment against [the specification](https://github.com/iqhive/iqmq/blob/main/the API contract). See Status. No performance, delivery-guarantee or compatibility claim is made until the reproducible evidence described there exists.
